## 🔑 Key Differentiators

1. **Cross-track:** Covers Healthcare + Public Safety simultaneously
2. **AI Routing:** Deterministic decision engine — explainable, fast, credible
3. **Real-time:** Socket.io pushes capacity changes live to all connected apps
4. **Indonesian context:** Jakarta floods, RSUP Fatmawati, BNPB, 119 emergency
5. **Demo-ready:** Pre-scripted mass casualty scenario plays itself in 90 seconds
